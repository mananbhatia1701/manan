# Manan Bhatia's website

Live site: https://mananbhatia1701.github.io/manan/

This repository preserves the layout, styling, text, links, and portrait of the former [MIT-hosted website](https://math.mit.edu/~mananb/). The homepage is `index.html`; its portrait is the relative asset `mb1.jpg`. The `.nojekyll` file makes GitHub Pages serve the static files directly.

GitHub Pages publishes the root of the `main` branch automatically. To update the site, edit `index.html` or replace `mb1.jpg` and commit the change to `main`. Keep links to local assets relative so they continue working at this project URL.

The biography and MIT email on the homepage are retained from the source site for fidelity; this copy does not claim they are current.
